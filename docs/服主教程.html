第一章 · 软件总览

软件总览

禁止上传光柱（PreventUpload）是方舟：生存进化服务端插件：一键禁止玩家通过光柱（Tribute）终端上传物品，并用红字提示引导玩家改用限时转移魔方跨图传送，从源头管住跨服物资流动。

🚫

拦截光柱物品上传

玩家把物品传入光柱终端的请求被服务器直接拒绝，跨服物资外流从此管住。

📣

屏幕引导提示

拦截的同时给玩家发送屏幕提示，文案、颜色、大小、时长均可配置（也可静默），玩家不懵、客服减负。

🌐

控制台编码自适应

兼容 ArkApi 3.54（GBK）与 3.55（UTF-8）两类服务器控制台，中文日志不乱码。

♻️

配置热重载

控制台或 RCON 执行 PreventUpload.Reload 即时生效，改配置无需重启服务器。

第二章 · 环境要求

环境要求

项目要求
操作系统Windows（64 位），插件为 x64 动态库
游戏服务端方舟：生存进化（ARK: Survival Evolved）专用服务器
运行依赖ArkApi（ServerAPI）插件框架，最低版本 3.5（插件 PluginInfo.json 中 MinApiVersion 为 3.5）
其他依赖无——不需要数据库，不需要额外运行库
第三章 · 部署安装

部署安装

  1. 确认 ArkApi 已安装

    服务器目录 ShooterGame\Binaries\Win64\ArkApi 存在，说明插件框架已装好 → 下一步。

  2. 运行一键安装脚本

    双击项目里的 一键安装.bat，它会把 PreventUpload.dll、PreventUpload.pdb、PluginInfo.json、config.json 四个文件复制到每台服务器的 ShooterGame\Binaries\Win64\ArkApi\Plugins\PreventUpload 目录（目录不存在会自动创建）→ 按提示选择是否额外部署停用副本 PreventUpload.dll.arkapi → 下一步。

  3. 重启服务器

    插件随服务器启动加载 → 控制台出现「先锋.禁止上传光柱(1.0) 先锋方舟服主群:138535385 作者QQ:711919」横幅 → 下一步。

  4. 验证拦截效果

    进游戏走到光柱终端，把物品放入上传 → 物品不会被传走，屏幕出现红字「服务器禁止上传光柱,请使用限时转移魔方跨图传送物资!」→ 部署成功。

脚本默认部署到 F:\ARK\Servers 下编号 1 2 3 的服务器；你的服务器路径或编号不同的话，先修改 一键安装.bat 顶部的 SERVER_BASE / SERVER_LIST 变量再运行。不想用脚本也可以手动复制上述 4 个文件到插件目录。
服务器运行期间插件文件被占用：安装、卸载、停用前请先关闭服务器，否则复制或删除会失败。
脚本用途
一键安装.bat把插件文件批量部署到各服务器插件目录
一键卸载.bat从各服务器删除插件文件并移除插件目录（删除前会确认）
一键附件.bat把 docs 目录下的教程附件复制到插件输出目录，随插件一起分发
一键清除.bat清理编译产生的临时文件与产物目录（源码开发用）
第四章 · 配置详解

配置文件说明

配置文件为 JSON 格式，位于每台服务器的插件目录：

ShooterGame\Binaries\Win64\ArkApi\Plugins\PreventUpload\config.json

完整默认内容（可直接照抄）：

{
  "ConsoleEncoding": "auto",
  "Notification": {
    "UploadBlock": {
      "Text": "服务器禁止上传光柱,请使用限时转移魔方跨图传送物资!",
      "Scale": 2.5,
      "Time": 60,
      "Color": "255,0,0,100"
    }
  }
}
JSON 里逗号、引号一个都不能少。建议用带 JSON 校验的编辑器修改；改前先备份。
config.json 必须存在且是合法 JSON：文件缺失或格式错误时插件会加载失败——控制台在启动横幅后紧跟一条错误日志，此时拦截功能不生效。
第四章 · 配置详解

配置总表

本表列出全部配置键与兜底值，可配合页面搜索定位；详细讲法见下一节。

配置键兜底值说明
ConsoleEncodingauto控制台中文输出的编码模式：auto=按控制台自动探测，gbk/ansi、utf8/utf-8=强制指定
Notification.UploadBlock.Text内置默认文案上传被拦时发给玩家的屏幕提示文案；设为空字符串则静默拦截不提示
Notification.UploadBlock.Color255,0,0,100提示颜色，格式 "R,G,B" 或 "R,G,B,A"（0-255）

Notification.UploadBlock.Time60提示显示时长（秒），须为正数
第四章 · 配置详解

ConsoleEncoding（控制台编码）

什么意思：插件在服务器控制台打印中文（启动横幅、日志）时使用的编码。ArkApi 3.54 的服务器控制台是 GBK、3.55 是 UTF-8；auto 会按当前控制台代码页自动选择转码，保证两类服务器上中文都不乱码。

兜底值：auto（键缺失、值非法或类型不对时都按 auto 处理，并在控制台黄字提示「ConsoleEncoding 值非法: xx , 已回落 auto」）

{
  "ConsoleEncoding": "utf-8"
}

怎么修改：可选值为 auto、gbk、ansi、utf8、utf-8（大小写不敏感）。控制台中文正常时保持 auto 即可；出现乱码时按服务器控制台实际编码强制指定。改完执行 PreventUpload.Reload 即时生效，无需重启。

第四章 · 配置详解

Notification.UploadBlock（上传提示气泡）

什么意思：玩家把物品上传光柱被拦截时，屏幕上弹出的提示气泡的完整外观——显示什么文字、什么颜色、多大字号、停留多久，全部由 Notification 下的 UploadBlock 节控制。

字段类型兜底值说明
Text字符串内置默认文案提示文案；空字符串 "" = 静默拦截，不弹提示
Scale数字2.5文字大小（显示缩放），须为正数；值越大字越大
Time数字60显示时长（秒），须为正数
Color字符串255,0,0,100颜色，格式 "R,G,B" 或 "R,G,B,A"，各值 0-255（越界自动钳制）；只写三段时透明度默认 100
{
  "Notification": {
    "UploadBlock": {
      "Text": "本服禁止光柱上传,跨图请找管理员!",
      "Scale": 3.0,
      "Time": 30,
      "Color": "255,165,0,120"
    }
  }
}

怎么修改：文案改任意中文；颜色按 RGB 换算填 0-255（如 "0,255,255,100" 是青色）；大小、时长填正数。任一字段缺失、类型不对或值非法（颜色格式错、数值非正数）时自动回落对应兜底值，并在控制台黄字提示原因；整个 UploadBlock 节不写则全部用默认。改完执行 PreventUpload.Reload 即时生效，无需重启。

配置文件需保存为 UTF-8 编码（默认提供的 config.json 就是），否则中文文案可能乱码。

命令权限作用改名配置键

第五章 · 命令用法详解

PreventUpload.Reload

作用：不重启服务器，重新读取 config.json。修改了 ConsoleEncoding 等配置后执行它立即生效。

PreventUpload.Reload
参数必填缺省值说明
无参数——本命令不带任何参数，直接输入整条命令即可

示例：PreventUpload.Reload（控制台输入：重新加载配置，成功后收到提示）　PreventUpload.Reload（RCON 工具中发送同一命令：RCON 客户端会收到文本回复）

反馈：成功时提示 Reloaded config（控制台执行显示为绿色消息）；失败时提示 Failed to reload config（红色消息，常见于 config.json 被改坏或读不到），同时服务器日志会记录具体错误原因。

第六章 · 常见问题

常见问题

装了插件但拦截没生效？
按顺序检查：① 控制台完全没有「先锋.禁止上传光柱(1.0)…」横幅 → 插件没被加载：确认已装 ArkApi（不低于 3.5）、文件放在 ShooterGame\Binaries\Win64\ArkApi\Plugins\PreventUpload 目录；② 有横幅但紧跟报错 → config.json 缺失或格式错误，修复后重启服务器；③ 都正常的话，确认改完文件后重启过服务器。
控制台中文乱码怎么办？
把 config.json 里的 ConsoleEncoding 按服务器控制台实际编码指定：ArkApi 3.54 服务器用 gbk，3.55 用 utf8，不确定就保持 auto 自动探测。改完执行 PreventUpload.Reload 立即生效。
改了配置必须重启服务器吗？
不用。在服务器控制台或 RCON 执行 PreventUpload.Reload 即可热重载，立即生效。只有更换插件 dll 时才需要重启。
能修改提示的文案、颜色、大小和显示时长吗？
都能。在 config.json 的 Notification.UploadBlock 节里：Text 改文案（空字符串 = 静默拦截）、Color 改颜色（"R,G,B,A" 0-255）、Scale 改字号、Time 改时长（秒）。改完执行 PreventUpload.Reload 立即生效。
怎么临时停用插件？
关闭服务器后，把 PreventUpload.dll 改名为 PreventUpload.dll.arkapi（ArkApi 的停用命名），重启服务器即不加载；想恢复就把文件名改回去再重启。
怎么彻底卸载？
关闭服务器后运行 一键卸载.bat（会从各服务器删除插件文件并移除插件目录），或手动删除 ArkApi\Plugins\PreventUpload 整个目录，然后重启服务器。
恐龙上传、角色上传也会被拦吗？
不会。本插件只拦截「物品上传光柱」这一个动作，恐龙与角色上传不经过此插件，按服务器自身设置运行。
